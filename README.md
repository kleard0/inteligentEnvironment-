# Projet environnement intelligent avec Mistral 7B 


## Installation 
- Cloner le répo
- Installer Docker 
- Télecharger l'image Docker de Mistral docker pull ai/mistral:7B-Instruct-v0.2
- run le projet avec "docker-compose up --build"
- "docker-compose down" pour arreter les conteneurs
- "docker ps" pour lister les conteneurs actifs
